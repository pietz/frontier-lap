# Frontier Lap

The AI labs as race cars: who has the best model lineup right now, and how the gaps changed over two years. One self-contained page: open `index.html`.

- `index.html`: the page. The standings live in the `race-data` block at the top (SNAPSHOTS text table, LABS, LOGOS).
- `research/`: where the standings come from.
- `docs/`: the original brief, naming rounds, screenshots.

Domain: frontierlap.com (free as of 2026-11-21, not bought yet).
